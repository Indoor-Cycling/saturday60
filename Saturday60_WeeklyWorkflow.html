THE SATURDAY 60 — Weekly Workflow

Spotify → Exportify → Build Sheet → drops → TSS check → print → MOWL import + Excel backup · Rules that ride along automatically: RPM beat-locked (1:1 or ½) · 110 RPM hard ceiling · no explicit versions · PLAYLIST FIRST — MUSIC LEADS

PHASE 1 — BUILD THE PLAYLIST IN SPOTIFY (ride order is everything)
1Build in exact ride order: Warm-Up → Segment 1 → bridge → Segment 2 → bridge → Segment 3 → Segment 4 finisher → Cool-Down. Playlist position = sheet position.
2Playback rules: crossfade 10 s · gapless ON · Automix OFF. Make the playlist public and download it for offline before class.
PHASE 2 — EXPORT THE PLAYLIST (titles + BPM + length)
1Use Exportify — the clock depends on it: exportify.app → export the playlist. Duration (ms) is exact; Chosic's mm:ss has lost the fraction and leaves the odd song a second out.
2Explicit is in the Exportify file — the import flags any explicit track. Explicit versions are banned: swap in the clean edit in Spotify and export again. Chosic only for a key audit (Camelot within segments; bridges reset).
PHASE 3 — IMPORT INTO THE BUILD SHEET
1Open the Build Sheet → Import Spotify export → choose the CSV. BPMs, lengths and RPMs fill; anything over 110 BPM is set to ½ automatically. Lengths round up to the whole second the way MOWL counts — Len 3:10 against MOWL's 3:09 is right. Explicit tracks are listed before the import and arrive flagged red.
2Fill the drops you already own: Drops library → Fill from library — every song marked in an earlier week gets its drop times and drill text back; only songs with none are touched. Not sharing this device's library? Import file → newest Saturday60-Drops file. Load before you Save, so exports stay a superset.
3Housekeep: ▲▼ or the jump dropdown to move a song · rename a section header, or trade two with ⇄ · set Ride mode where defaults don't fit · tap-test any BPM that looks doubled or halved.
PHASE 4 — DROPS VIA THE SELECTOR (phone) — for whatever Phase 3 could not fill
1Start with what you already have: Drops library → Fill from library. Every song you have marked before gets its drops, colour coding and downbeat back in one tap — only songs with none are touched.
2Mark the rest: tap a work-block song's ◎ and capture its drops — split-screen with Spotify and Mark drop live, with Musixmatch on the flip to Chorus, Add by hand from Spotify's elapsed time (most accurate), or hold a phrase boundary half a second to take it off the grid. Tap a chip to colour-code it.
2bTimes already in hand? Paste a list → Add all keeps what you captured, Replace starts the song over. Commas, spaces or line breaks all separate.
3While you are there, set each song's length — type it or take it from timer. Lengths travel with the songs into the sheet's Len column.
4Get them to the sheet: type into Drop times, or Send to sheet → Import from Selector. Pick ONE import route per week. Then bank the week: Drops library → Add this playlist.
PHASE 5 — CHECK, SCORE, PRINT AND LOAD MOWL
1Check the sheet before you print: no amber length boxes (a slot that changed song lost its runtime), Σ close to 60:00, no +n? in the headers. The last Σ is MOWL's total — check it against the Session Designer pill.
2Score it: Send → Build Sheet, copy the code → TSS Planner → Import code. First-60 TSS 65–75 (cap 75), no ⚠. Over the cap: ease warm-up, builds and recoveries first. Both the Planner and step 4 read timed cues — 0:00–1:16 Z2 base · 1:16–1:34 Z3 pickup 1 of 2 — one entry for every change the rider makes, gear steps included.
3Build Sheet → Print / Save as PDF; the finished week joins the kit.
4MOWL: Build Sheet → Export for MOWL (fix anything the preview flags) → upload at login.mowl.com/profile/import → My Workouts → Edit Workout → import music → the playlist. Nudge work intervals onto the Drop times; RPM and Cue Cards don't import. The cool-down arrives as the teal Cooldown; split segments at the bridges (drag below L1) and name them on save.NEW
PHASE 6 — EXCEL BACKUP AND CHARTS
1FIRST: Developer → Macros → ClearPlaylist. Wipes last week's songs, Pointers and intervals — all keyed to row position. Skip it and a shorter ride leaves the tail of the old one in your totals.
2Build Sheet → Export for Excel. In the workbook click B2 on My Playlist and paste (block B:J). Pointers (K) and Avg RPM (L) are never overwritten. Elapsed should match MOWL; if it runs long, the Build Sheet and the .bas are out of step — update both.
3Pick the gears: Gear (M3) 1–24, Gear (M3i) 1–72. Add intervals on the Intervals sheet for a weighted Avg RPM. The Load curves and segment/cadence charts update themselves.
4Developer → Macros → FormatPlaylistPrint. Sizes the fold-up sheet to your song count and drops empty slots. Print double-sided, flip on the LONG edge, fold in half — ride detail front, song + artist back.

The tools live at https://indoor-cycling.github.io/saturday60/ — one installed app, working offline. Data lives per device: each tool's Backup writes a dated file you can Restore anywhere, and transfer codes are the quick courier between phone and desktop. After uploading a change, bump the version in sw.js and tap Update now; the hub's Check for updates confirms it landed.
